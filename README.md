# Default Community Health Files

GitHub Organization [azalea-works](https://github.com/azalea-works) 内で共通して使うものを管理するリポジトリです。

## 構成

以下のものを管理しています。

|  | ファイル | 備考 |
|:-|:-| :- | 
| Issue テンプレート | [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | 日英両方に対応しています。 |
| PR テンプレート | [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | 日英両方に対応しています。 |
